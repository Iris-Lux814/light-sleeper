# 做梦的研究依据

浅眠做梦部分的设计，每一条都对应下面的研究结论。

## 1. 大多数梦其实挺「正常」
- Snyder 分析实验室里收集的 REM 梦报告，典型的一个是：清楚、连贯、有细节的现实情境，做梦的人跟别人一起做很平常的事，而且常常在说话。
- 60%~80% 的梦连贯度评为「高」，评为「低」的不到 5%。荒诞是有的，但一般一个梦里就一两处。
- → 设计：一个梦讲一件事，怪的地方只留一两处，而且梦里的他不觉得怪。
- 来源：[Domhoff：梦里的怪异](https://dreams.ucsc.edu/Library/domhoff_2007b.html)，[Domhoff：梦的内容](https://dreams.ucsc.edu/Library/domhoff_2005a.html)

## 2. 连续性假说：梦接着白天，但只取碎片
- 白天在某件事上花的时间越多，梦到它的比例越高。Domhoff 更强调心里惦记、关心的事，Schredl 更强调白天有情绪分量的经历。
- 白天的东西进梦时通常只是碎片。
- 读书、写字、算数、用电脑这类专注的认知活动很少出现在梦里。
- → 设计：素材优先挑放不下的事和有情绪的碎片，每个梦只拿一两样；不写读写和屏幕。
- 来源：[Schredl 2003](https://pubmed.ncbi.nlm.nih.gov/12763010/)，[Domhoff 2017](https://dreams.ucsc.edu/Library/domhoff_2017.html)，[连续性研究综述](https://journals.sagepub.com/doi/10.1177/02762366241254818)

## 3. 白天残留和梦的延迟效应
- 前 1~2 天的事最容易进梦；2~4 天前的事反而少；5~7 天前的事又多起来，主要是对个人有意义的事。
- → 设计：素材里单独有「五到七天前有分量的事」这一类。
- 来源：[Nielsen 等 2004 的复现](https://www.sciencedirect.com/science/article/abs/pii/S1053810010001480)，[延迟进梦的多是有个人意义的事](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6849581/)，[REM 和 NREM 的延迟效应](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0026708)

## 4. 前半夜和后半夜的梦不一样
- NREM 的梦短、碎、像在想事情；REM 的梦长、像故事、情绪浓、更怪。
- 越到后半夜，梦越长、情绪越浓。
- → 设计：梦跟着睡眠周期排，前半夜短、后半夜长。
- 来源：[前半夜和后半夜的梦](https://www.sciencedirect.com/science/article/abs/pii/S1053810020305389)，[一夜里梦的情绪怎么变](https://www.biorxiv.org/content/10.1101/2025.06.26.661683v1.full)，[认知神经科学概述](https://en.wikipedia.org/wiki/Cognitive_neuroscience_of_dreams)

## 5. 梦的情绪偏负面，而且很「社交」
- Hall / Van de Castle 常模：梦里的情绪多数是负面的，倒霉事和冲突也常见。
- 梦比醒着更社交，一个梦平均有 2~4 个人。
- → 设计：情绪配比偏负面（焦虑、困惑），梦里要跟人有来回。
- 来源：[Hall/Van de Castle 编码系统](https://dreams.ucsc.edu/Library/fmid2.html)，[社交模拟理论的实证检验](https://www.sciencedirect.com/science/article/abs/pii/S1053810017302283)，[Domhoff 2018：梦是社交模拟吗](https://dreams.ucsc.edu/Library/domhoff_2018.html)

## 6. 记得多少，看夜里醒了多少
- 梦记得多的人，入睡后醒着的时间更长（30 分钟对 14 分钟），夜里醒得更频繁。这就是 arousal-retrieval 模型：梦要在短暂醒来时才编进记忆。
- 醒来几分钟之内，大部分梦就忘了；醒来马上碰到别的事，忘得更多。
- → 设计：睡得好的晚上记得少，半夜醒过的记得多；醒前那个梦最容易记得。
- 来源：[Eichenlaub 等：夜里醒得多解释了记梦多](https://pmc.ncbi.nlm.nih.gov/articles/PMC6803546/)，[干扰假说再检验](https://journals.ub.uni-heidelberg.de/index.php/IJoDR/article/download/364/pdf_5/)，[早上能不能记住梦](https://www.nature.com/articles/s44271-025-00191-z)

## 7. 梦话
- 录下的 883 段梦话里，59% 根本不是话（嘟囔、叫、气声、笑）。最常说的词是「不」，否定句占 21%，问句占 26%。
- 梦话多出现在深睡，不一定对应正在做的梦。
- → 设计：梦话大多是嘟囔和「不……」，跟做不做梦分开。
- 来源：[梦话研究报道](https://medicalxpress.com/news/2018-01-reveals-talkers.html)，[Sleep-talking](https://en.wikipedia.org/wiki/Sleep-talking)
